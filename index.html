About
GeoRoots Locator
Offline-capable GPS data collection and mapping progressive web app.
All data is stored locally on your device, no information is transmitted to ANY servers.
This app is free and open source, and all code is available on GitHub. You are welcome to submit your contributions to the project. Any issues or suggestions, please report them on GitHub Issues or via email to info@georoots.eu.
For more free tools, visit georoots.eu.
Version: 2.6.4
